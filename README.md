# Сайт ИП Титлянова А. Е. — Scratch

Готовая статическая версия для GitHub Pages.

## Что изменено
- Сохранена структура и стилистика исходного сайта.
- На главную страницу добавлен блок «План обучения Scratch» по предоставленному DOCX.
- Добавлен специальный раздел `sveden/` с обязательными подразделами приказа Рособрнадзора от 04.08.2023 № 1493 с учетом редакции 2026 года.
- Добавлена базовая машиночитаемая разметка `itemprop` для ключевых сведений.
- Исходный `education.html` оставлен как перенаправление на новый раздел, чтобы старые ссылки не ломались.

## Важно перед публикацией
1. Проверить фактическое наличие лицензии и разместить актуальную выписку/ссылку, если лицензия уже получена.
2. Добавить утвержденные локальные нормативные акты и документы по платным образовательным услугам.
3. Заполнить персональный состав педагогических работников.
4. Уточнить вакантные места и финансово-хозяйственные сведения.
5. Сверить учебный план: предоставленный файл содержит 6 модулей на 16 академических часов, а исходный сайт заявляет 24 академических часа.
6. Изображения сейчас подключаются по абсолютным URL из исходного GitHub Pages, чтобы визуал оставался идентичным. При необходимости их можно скачать в `assets/` и заменить URL на локальные пути.

## Публикация
Загрузите содержимое этой папки в корень репозитория GitHub Pages и включите Pages для ветки `main`.
